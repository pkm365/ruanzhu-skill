# 1 软件概述

## 1.1 简介

设备点检管理系统面向制造车间的设备管理部门，用于组织设备的日常点检工作。设备管理员在系统中维护设备台账和点检标准，系统按周期自动生成点检任务并分配给点检人员，点检人员在现场通过手机或电脑完成录入，不合格项自动进入异常处理流程，管理人员在统计分析页面查看完成率和异常趋势。

## 1.2 功能特点

系统包含设备台账、点检标准、点检任务、异常处理、统计分析五个模块。点检标准按版本发布，历史记录始终能追溯到当时依据的标准；任务由系统按周期自动生成，无需人工排班；关键项不合格必须上传照片并进入异常处理，处理过程按发现、指派、处理、复检、关闭的顺序流转，不能跳步。

## 1.3 运行环境

| 项目 | 要求 |
|---|---|
| 服务器操作系统 | Windows Server 2019 或 Ubuntu 22.04 |

# 3 设备台账

## 3.1 设备列表

功能描述：查看和维护全部设备的基础信息。

操作步骤：

1. 点击左侧菜单"设备台账"，进入设备列表页面。列表按车间、产线分层展示，每行显示设备编号、设备名称、型号、安装位置、责任人和状态。
2. 在顶部搜索框输入设备编号或名称，点击"查询"，列表只显示匹配的设备。
3. 点击"新增设备"，在弹出窗口中填写设备编号、名称、型号、所属车间、产线、安装位置和责任人，设备编号不能与已有设备重复，保存后新设备出现在列表中。
4. 点击某行的"编辑"可修改除编号以外的信息；点击"停用"后设备状态变为停用，系统不再为其生成点检任务。

## 3.2 设备二维码

功能描述：为每台设备生成二维码，供现场扫码进入点检任务。

操作步骤：

1. 在设备列表中勾选一台或多台设备，点击"打印二维码"。
2. 系统生成包含设备编号和名称的二维码标签页面，点击"打印"输出到打印机，贴在设备上。

# 4 点检标准

## 4.1 标准列表与新建

功能描述：按设备型号定义点检项目。

操作步骤：

1. 点击左侧菜单"点检标准"，进入标准列表页面，每行显示型号、标准版本、状态和发布时间。
2. 点击"新建标准"，选择设备型号，进入编辑页面。
3. 点击"添加项目"，填写检查部位、检查方法、判定标准、点检周期（每日、每周、每月）、是否关键项。判定标准可选择"目视合格/不合格"或"数值范围"，选择数值范围时需填写上下限和单位。
4. 编辑完成后点击"保存草稿"，草稿状态的标准可以继续修改。

【截图预留：请插入「点检标准编辑」截图。】

## 4.2 标准发布

1. 在标准列表中选择草稿状态的标准，点击"发布"。
2. 系统生成新的版本号，标准状态变为已发布，此后不能修改；同型号旧版本自动变为已停用，但历史点检记录仍指向其当时使用的版本。
3. 需要修改已发布标准时，点击"复制为新草稿"，在副本上修改后再次发布。

# 5 点检任务

## 5.1 任务生成与分配

功能描述：系统根据已发布标准中的周期自动生成任务。

每日凌晨系统为所有启用状态的设备按标准周期生成次日任务：每日项目每天生成一次，每周项目在每周一生成，每月项目在每月一日生成。任务默认分配给设备的责任人，设备管理员可以在任务列表中点击"改派"重新指定点检人。

## 5.2 执行点检

操作步骤：

1. 点检人登录后，在"点检任务"页面看到自己的待办任务，也可以用手机扫描设备二维码直接打开该设备当天的任务。
2. 任务页面按标准逐项列出检查部位、方法和判定标准。目视项目选择"合格"或"不合格"；数值项目输入实测值，超出上下限时系统自动标为不合格。
3. 关键项不合格时，必须点击"拍照"上传现场照片并填写异常说明，否则无法提交。
4. 全部项目填写完成后点击"提交"，任务状态变为已完成，提交后不能修改。未在当天完成的任务次日标记为超期。

# 6 异常处理

功能描述：集中处理所有点检不合格项。

操作步骤：

1. 点击左侧菜单"异常处理"，列表显示全部异常，每行包含设备、检查部位、发现时间、发现人、当前状态。状态分为待指派、处理中、待复检、已关闭。
2. 设备管理员点击待指派的异常，选择维修人员并填写要求完成时间，点击"指派"，状态变为处理中。
3. 维修人员在自己的异常列表中打开该项，填写处理措施和实际完成时间，可上传处理后照片，点击"处理完成"，状态变为待复检。
4. 原点检人收到复检提醒，到现场确认后点击"复检通过"，状态变为已关闭；不通过则填写原因，异常退回处理中。

# 7 统计分析

功能描述：按设备、车间、时间段统计点检情况。

操作步骤：

1. 点击左侧菜单"统计分析"，选择统计范围（车间或设备）和时间段，点击"查询"。
2. 页面上方显示点检完成率、及时率和异常发生率三个指标，下方是按日的趋势图和按设备的明细表。
3. 点击"导出"，系统生成表格文件供下载。

# 8 常见问题

1. 为什么某台设备没有生成点检任务？请确认设备状态为启用，且其型号存在已发布的点检标准。
2. 提交任务时提示"关键项需上传照片"怎么办？关键项选择不合格后必须拍照并填写说明，补充后即可提交。
3. 已发布的标准写错了怎么改？已发布标准不能直接修改，请使用"复制为新草稿"，修改后重新发布。
4. 异常为什么无法直接关闭？异常必须经过指派、处理、复检三个环节，由发现人复检通过后才能关闭。
